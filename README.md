# hxyfront-62006 珠宝镶嵌宝石分拣

面向珠宝镶嵌工作室的宝石分拣与镶嵌回执核销前端系统。

## 功能

- **宝石台账**：记录宝石编号、种类、形状、克拉重量、尺寸、净度、颜色、切工、镶嵌位置、分拣批次与缺陷备注，按订单查看宝石清单。
- **尺寸/形状/批次筛选**：四个尺寸桶（≤2.5mm、2.6–4.0mm、>4.0mm）带实时计数，筛选结果随核销同步变化。
- **镶嵌位置示意图**：主石位、围石A/B组、配石位环形示意图，点击位置可聚焦，橙圈标出缺陷备注。
- **回执台**：
  - 师傅镶嵌完凭便签交回执，每张回执绑定一个订单，记录交付时间、师傅和报成品数。
  - 裸石按原单逐颗核对：缺件、串单（实际编号属于别的订单）、编号不符（查无此号/同单错号/成品数不符）一律列出冲突并**挡住核销**。
  - 冲突逐条处理（缺件核销、改正编号、串单改配、以核对为准等）后才能确认核销。
  - 核销后缺件或已改配的裸石从原单核销掉，成品计入成品清单，待镶数与尺寸筛选同步更新。
  - 核销前台账侧改配裸石，该订单未核销回执自动退回「待处理」并附退回说明。
- **本地持久化**：数据存于浏览器 localStorage，重开页面后未核销回执与冲突记录仍在；无后端、无额外依赖。

## 代码结构（三个业务文件）

| 文件 | 职责 |
| --- | --- |
| `src/business/ledger.ts` | 台账存取：类型、localStorage 读写、种子数据 |
| `src/business/writeoff.ts` | 核销判断：逐颗核对、冲突判定与处理、核销执行、核销前改配、统计与筛选（纯逻辑） |
| `src/business/ReceiptDesk.tsx` | 页面交互：回执台、台账视图、筛选、位置示意图（React 组件） |

`scripts/verify.ts` 是纯逻辑验证脚本，不参与构建。

## 技术栈

React + Vite + TypeScript，未引入任何新依赖；React 类型由 `src/react-shims.d.ts` 本地最小声明提供。
